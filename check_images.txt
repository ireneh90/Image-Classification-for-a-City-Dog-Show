Questions regarding Uploaded Image Classification:

1. Did the three model architectures classify the breed of dog in Dog_01.jpg to be the same breed? If not, report the differences in the classifications.

Answer: Yes. All three model architectures classified Dog_01.jpg as a Golden Retriever.


2. Did each of the three model architectures classify the breed of dog in Dog_01.jpg to be the same breed of dog as that model architecture classified Dog_02.jpg? If not, report the differences in the classifications.

Answer: Yes. ResNet, AlexNet, and VGG all classified both Dog_01.jpg and Dog_02.jpg as a Golden Retriever.


3. Did the three model architectures correctly classify Animal_Name_01.jpg and Object_Name_01.jpg to not be dogs? If not, report the misclassifications.

Answer: Yes. All three model architectures correctly classified Cat_01.jpg and Coffee_mug_01.jpg as not dogs. Cat_01.jpg was classified as “Egyptian cat, cat”, while Coffee_mug_01.jpg was classified as “coffee mug”. There were no dog/non-dog misclassifications.


4. Based upon your answers for questions 1. - 3. above, select the model architecture that you feel did the best at classifying the four uploaded images. Describe why you selected that model architecture as the best on uploaded image classification.

Answer: I would select ResNet as the best model for these uploaded images. All three architectures produced the same correct classifications: they identified both dog images as Golden Retrievers and correctly classified the cat and coffee mug as not dogs. However, ResNet completed the task with a shorter reported runtime than VGG. AlexNet achieved the same classifications and reported runtime as ResNet, so their performance on these four images was effectively tied.
